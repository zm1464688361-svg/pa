## 2. 原型覆盖的页面状态说明

- **主流程态**：待支付（倒计时）→ 已确认（核销码）→ 已核销 → 服务中 → 已完成。
- **取消分支态**：自助取消（≥2h）直达退款；临近取消（<2h）→ 审核中 → 通过（退款）/驳回（复活）；退款 处理中→到账/失败→重试→终态失败。
- **异常态**：名额竞争失败页、时段已开始拒绝、异常支付待处理、退款失败跟进、未到店。
- **管理态**：发布时段、日清四指标 + 明细、未到店标记。

每个业务操作都有对应的"结果页/失败原因"展示，满足题面"页面可发起业务、查询结果和展示失败原因"的要求；实现时页面可合并为少量标签页 + 卡片，但状态展示必须齐全。

## 3. 与原型的差异说明（实现允许的简化）

- 原型中"模拟支付成功"按钮点击后由 pay_sim 异步回调确认，页面提供轮询刷新。
- 原型示例订单号/核销码（A001、A008 等）为演示数据，实现按自增规则生成。
- 页面样式做轻量还原（同一墨绿主题），不追求像素级一致；但信息结构与状态文案必须对应。
