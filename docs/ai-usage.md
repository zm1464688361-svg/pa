## 2. AI 生成内容中学生实际审核过的部分

1. **业务规则**：Agent 初版把"审核通过的取消"与"自助取消"共用一条释放名额路径，学生要求按题面拆分为"退款成功后释放 + 幂等标记"，对应 `releaseSlotOnce`。
2. **越权处理**：Agent 初版只判断 RPC 传输层错误，业务错误码被静默放行；学生发现主人能打开店长页，要求统一拦截 `Base.Code != 0`（`ca5ec6c`）。
3. **教学时钟**：Agent 初版页脚直接用 `time.Now()`，学生按"所有业务时间走时钟"的约束要求改为 `Clock.Now()`（`c2462f0`）。
4. **CI 门禁**：Agent 首版覆盖率步骤未建输出目录导致误判，学生按失败日志要求加目录并复跑（`cd81b80`）。
